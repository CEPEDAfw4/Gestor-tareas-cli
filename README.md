 
 # Gestor de Tareas CLI

 Proyecto desarrollado en Python para gestionar tareas desde la terminal.


 ## Requisitos previos
 - Tener instalo Python 3
 - Tener instalado Git para el control de las versiones
 - Contar con una computadora con acceso a una terminal 
 - No se necesitan librerias externas para ejecutar el programa


 ## Funciones
 - Agregar tareas 
 - Listar tareas 
 - Completar tareas 
 - Eliminar tareas 
 - Salir del porgrama 


 ## Ejecucion 
 python app.py
